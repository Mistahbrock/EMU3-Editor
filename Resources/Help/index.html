Getting started

EMU3 Editor edits E-MU sampler disks and banks on the Mac: Emulator IV / E4 / E64 / E6400 (EOS) banks, and older Emulator 3X / ESI-32 banks. It works on a disk image, a bank file or the disk your sampler is reading.

  1. Open something. File ▸ Open Disk Image… (⌘O) for a whole disk, or Open Bank File… (⇧⌘O) for a single bank. Files dropped on the app icon open too.
  2. Look around. The Disk page lists banks, folders and samples like the sampler's own Disk screen.
  3. Edit. Select a sample on Samples, or a preset on Presets.
  4. Save. Save Bank (⌘S). A backup of the loaded bank is written first.
Hover over most buttons for a short hint. Hints can be switched off in Settings.

Master

The left side holds the sampler-style screens (MIDI, Setup, Bank, FX) and the utilities Assign Key, Channel Volume and Tones. The Current bank group opens and saves banks and sends a sample to the sampler's disk.

The sampler memory line is for information. Sample RAM is physical and cannot be read over SCSI or MIDI.

Contrast (Setup page): the screens change at once, like on the sampler. Hold ⇧ and scroll over the Contrast control to change the colour of the green screens. Double-click it to set contrast and colour back to the default.

Disk

Pick a disk and press Return (or double-click) to open it; Esc goes up one level. A bank opens into the editor and shows its samples. Load… brings a bank into the editor without leaving the list.

Right-click a bank for its type, Open, Show in Finder and, for 3X banks, Convert.

Samples

  • Waveform: drag the loop markers. Hold ⌥ to snap to a zero crossing.
  • Audition: Space plays or stops. Looped samples sustain in the loop.
  • Sample edit: Normalize, Reverse, Fade In/Out, Remove DC, Crop Loop, X-Fade Loop. Edit ▸ Undo works.
  • Convert: Export WAV and Replace from a WAV or other audio file.
  • Transfer: SMDI (SCSI), MIDI Dump (Sample Dump Standard) and To Disk (copy to the sampler's disk).
  • Zoom: + −, 0 fits, L zooms to the loop.

Samples that do not follow the known layout are shown but locked, and are written back byte for byte.

Presets

Pick a preset on the left. The middle shows its structure (preset ▸ voices ▸ sample references); the right shows the parameters, grouped like the sampler's Preset Edit menus. Changes go straight into the preset.

  • EOS presets (E4B): all parameter tables; you can add or remove sample references and duplicate or remove voices.
  • 3X / ESI-32 presets: header, realtime controls, zone table and key map are editable. Voice blocks only show the sample number.

Right-click a preset for its type and, for 3X presets, Convert to EOS….

Tools

  • Disk images: create an empty, EOS-formatted floppy (1.44 MB) or disk image.
  • BlueSCSI SD card: copy an image to an SD card, write bluescsi.ini.
  • Sampler link: serve an image folder to the sampler through the board (see below).
  • Sampler: find the sampler on the SCSI bus, send samples by MIDI, show the disk it uses.
  • Mounts: the disks that are mounted now. Double-click one to open it.

Converting 3X / ESI-32 banks

Emulator 3X and ESI-32 banks cannot be loaded by an E4 / E64 / E6400 as they are. The editor can write an EOS (E4B) copy of them. The original is never changed.

  • When you open a 3X bank the editor offers to convert it (can be switched off in Settings).
  • Right-click a 3X bank in the Disk list, or a 3X preset on the Presets page, and choose Convert. Converting a preset takes only the samples it uses.
Check the result by ear. Samples, preset names, key ranges, velocity splits and the sample assignment are converted. Tuning, envelopes, filters, root key and pitch-bend range are not decoded; converted voices use EOS default values. A converted bank has not been proven on a real sampler yet.

Sampler & BlueSCSI

The sampler usually sits at SCSI ID 6 and the BlueSCSI board at ID 7; the served disk takes another ID (for example 3). Use Find Sampler (SCSI scan)… on the Tools page to read the model and EOS version.

When the sampler's disk is mounted on the Mac, To Disk and Send Sample to Sampler Disk… copy straight to it. If Save to the sampler's disk automatically is on in Settings, a bank that was opened from the sampler's disk is written back a few seconds after you stop editing.

MIDI transfer

MIDI Sample Dump… (⌘D) sends the selected sample to the sampler, requests one by number, or waits for a dump started from the sampler. Choose the MIDI ports and device ID in the dialog. Never guess SysEx: only the documented dump messages are used.

Settings

EMU3 Editor ▸ Settings… (⌘,):

  • Folders for file dialogs: each dialog opens in the folder you used last. Choose… pins a folder; Last Used goes back to following your last one.
  • Auto-save to the sampler's disk, convert offer for 3X banks, tool tips on/off.
  • Set Defaults puts all of these back to the start values.

Safety

  • Saving writes a backup of the loaded bank to ~/Library/Application Support/EMU3 Editor/Backups first.
  • Converting never changes the original file.
  • Do not write to a disk image while the sampler is using it, and unmount it from the Mac before you power the sampler up.

Troubleshooting

The sampler does not see my disk

Check the SCSI IDs: sampler 6, board 7, disk not equal to either. Run Find Sampler and check the USB cable to the board.

A bank will not open

Only EOS (E4B) and Emulator 3X / ESI-32 v3 banks are read. Original Emulator III banks are not supported yet.

A converted bank sounds wrong

Tuning, envelopes and filters are not converted (see above). Fix them in the Presets page.

MIDI transfer does nothing

Pick the right MIDI ports and device ID in the dialog; many samplers answer to ID 127 (all).
